# Markdown 渲染工具

## 打开方式

双击或在浏览器中打开 `Markdown 渲染工具.html`（需联网加载 marked / DOMPurify / highlight.js CDN）。

## 30 秒示例

1. 左侧粘贴或输入 Markdown
2. 右侧即时预览；残缺语法在「宽容模式」下自动修复
3. 需要整理源码时点 **格式化**

## 行为说明

| 开关 | 开 | 关 |
|------|----|----|
| 宽容模式 | 预处理修复后再渲染 | 仅规范化换行，严格解析 |
| 智能换行 | ① 一行内的 `##` / `###` / 列表 / `---` 自动拆行；② 段内单个 `\n` 显示为换行 | 不拆结构行；段内换行合并为段落 |
| `` ```markdown `` 块 | 围栏内 Markdown **渲染为预览**（虚线框区域） | 显示为高亮源码 |

## 表格说明

- 仅识别标准 GFM 表格（行首尾 `|`，或至少 3 列），不会把正文里的单个 `|` 当成表格
- 不再为每一行重复插入 `---` 分隔线

内容与本机设置自动保存到浏览器 `localStorage`。

## 快捷键

| 按键 | 作用 |
|------|------|
| Ctrl+Shift+F | 格式化源码 |
| Ctrl+S | 立即保存到本地 |
| Ctrl+O | 打开 .md 文件 |
| Ctrl+E | 导出 HTML |
| Ctrl+F | 聚焦源码搜索 |

## 已知限制

- 依赖 CDN，离线首次打开可能无法渲染
- 不执行 Markdown 内嵌 HTML 脚本（经 DOMPurify 过滤）
- 超大文档（>约 2MB）可能卡顿

## 变更摘要（W3）

- 本地自动保存（内容 + 开关 + 分栏宽度）、拖放/打开文件、导出 HTML
- 分栏可拖动调整；搜索支持上/下跳转
- 增强容错：任务列表 `[X]`、BOM、全角空格等
- marked 输出后处理：表格外层包裹、外链 `noopener`
- Toast 提示；状态栏显示行数/字数
